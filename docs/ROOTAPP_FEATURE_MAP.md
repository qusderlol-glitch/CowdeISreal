## Точки интеграции, уже готовые в коде

| Точка | Где | Для чего |
|---|---|---|
| Модульные боты/команды | `src/lib/commands.ts` (реестр, справка, автодополнение), `public.run_command()` в миграции (исполнение на сервере) | Любая функция RootApp, вызываемая командой в чате |
| Настройки модуля на уровне сообщества | таблица `community_bots (bot_key, enabled, settings jsonb)` | Включение/отключение и конфиг функции владельцем сообщества |
| Журнал вызовов | `bot_command_log` | Аудит использования и ошибок |
| Права | битовая маска `PERM` (`src/lib/permissions.ts` ⇄ SQL) | Новые права добавляются свободным битом в обоих местах |
| Название бренда | `src/lib/brand.ts` | Всё приложение уже называется RootApp Community |

## Как добавить функцию RootApp
1. Добавьте строку в таблицу выше (источник обязателен).
2. Если функция — команда: `docs/DIGGERS_BOTS_TODO.md` → «Как добавить модуль» (тот же механизм).
3. Если функция — отдельный экран: страница в `src/pages`, данные — таблица + RLS + RPC в новой миграции `supabase/migrations/<дата>_rootapp_<имя>.sql`.
